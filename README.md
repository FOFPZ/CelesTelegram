# TG Web — веб-клиент Telegram на официальном API
Минималистичный клиент Telegram: Python + FastAPI + Telethon (MTProto) на бэкенде,
адаптивный веб-интерфейс в стиле Telegram и установка как приложение (PWA) —
на телефон или рабочий стол.

Работает напрямую с дата-центрами Telegram, без сторонних серверов и посредников.

# Частые вопросы

«Код истёк» — код живёт несколько минут, нажми «Отправить код ещё раз».
Если Telegram присылает код не в SMS, а в служебный чат «Telegram», посмотри там.

«Нужен пароль двухфакторной аутентификации» — у аккаунта включён облачный пароль
(Настройки → Конфиденциальность → Двухэтапная проверка). Введи его на шаге «Пароль 2FA».

«Слишком много попыток. Подожди N мин.» — ограничение Telegram (FloodWait),
связано с частыми запросами кода. Просто подожди.

Сообщения обновляются не мгновенно — сейчас опрос раз в 3 секунды.
Следующий шаг развития: push-обновления Telethon (events.NewMessage) и SSE/WebSocket,
а также медиа, реакции, ответы и удаление сообщений.
